This is free of cost browser just like google follow the steps and run the file :-
1. download and open the file
2. the following libraries should be installed in your PC
   a. PyQt5
   b. PyQtWebEngine
   if not copy and paste the following command in your terminal/cmd

   For Windows
   pip install PyQt5
    PyQtWebEngine

   For MacOS
   pip3 install PyQt5
    PyQtWebEngine

   For Linux OS
   pip3 install PyQt5
    PyQtWebEngine
